Technical Architecture

Under the Hood:
How Wave Music Operates

An engineering overview of our low-latency audio pipeline, intelligent state management, and real-time frontend syncing.

The 4-Step Streaming Engine

From search query to crystal-clear sound in under 300ms

1

Intelligent Search Query

User input triggers debounced asynchronous requests across local cache and JioSaavn APIs, normalizing track metadata and artwork in parallel.

2

Direct Stream Resolution

Our server-side engine resolves high-bitrate (320kbps/160kbps) audio URLs directly from source CDNs, eliminating transcoding and third-party extractors.

3

HTML5 & Web Audio Node

Audio is ingested into an HTML5 Audio node connected to a Web Audio API AnalyserNode for real-time waveform calculations and Dynamic Island visualizations.

4

Smart Queue Prefetching

While the current track plays, the next track in the queue is automatically prepared in memory, enabling instant, gapless playback transitions.

Local-First State Management

Your library and preferences stay safely on your machine

Wave Music operates on a reactive single-state model (`state.js`). Whenever you like a song, create a playlist, or change equalizer levels:

  • State Mutation: The in-memory reactive state object is immediately updated.
  • DOM Sync: Specific UI components re-render without full page refreshes.
  • Storage Persistence: Changes are saved to localStorage and IndexedDB for instant offline access.

Zero Server Tracking

Because Wave Music uses local-first state, we never track your listening habits, personal playlists, or history on our servers. Complete privacy guaranteed.
